# Конвертер единиц

Локальная одностраничная страница. Никуда не опубликована.

## Как открыть

Откройте файл `index.html` в браузере (двойной щелчок или перетащите в окно браузера). Интернет и установка программ не нужны.

## Что внутри

- `index.html` — страница
- `styles.css` — оформление
- `app.js` — интерфейс калькуляторов
- `conversions.js` — коэффициенты пересчёта
- `favicon.svg` — значок сайта
- `tests/test-conversions.js` — проверка коэффициентов (`node tests/test-conversions.js`)

Заглушки Google AdSense на странице есть, сам рекламный код не подключается.
